# GitHub Portfolio Auditor

Comprehensive tool to scan your entire GitHub account and generate detailed portfolio reports.

## Features
- Repository discovery and metadata
- Per-repo analysis (docs, stack, CI/CD, security)
- Code intelligence with AI summaries
- Cross-repo insights (duplicates, merges)
- Quality scoring and action plans
- Multiple output formats (HTML, PDF, JSON, etc.)
- Incremental scanning

## Installation
```bash
pip install -e .
```

## Usage
```bash
gha scan --help
```

See [docs](docs/) for details.
